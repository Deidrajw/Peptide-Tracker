# Nexus v0.9.20-beta — Unified Kit Experience

**Release status: CODED ON PR #110 / NOT MERGED / NOT DEPLOYED / QA PENDING.** Cloudflare production remains the separately verified v0.9.19-beta until this release is merged and independently validated.

## User-facing changes
- **Stash:** Premixed kits and single-compound kits share the same card renderer, inventory headings, Open New Vial action, Prepare action, and Overview / Vials / History structure. The blend-only card renderer is deleted.
- **Open Vial:** Blend entry now opens the exact same form as normal kits, with the same vial count, mg-per-vial, BAC, recon date, expiry days, notes and confirmation control. Blend kit strength is read-only inside this action to protect its defined composition.
- **Log Dose:** Blend entry now uses the standard Log Dose sheet, source/date/time, site, observations, allocation, review and confirmation footer. A short composition breakdown displays component mg proportions; only **one blend-level administration event** is recorded.
- **Inventory:** Premixed prepare and dose allocations link to the physical vial ledger. Exact transaction IDs enable undo and safely protect legacy records with ambiguous source linkage from destructive modification.

## Data protection
- No automatic conversion, deletion or rewrite of older constituent doses or saved KLOW kit entries. Preexisting saved storage key and backup formats are unchanged.
- Blend ratios are formulation metadata, not independent dose administrations; exact ingredient amounts are calculated from the user's saved vial composition.
- If an old dose has no exact linked vial transaction, destructive reversal is blocked rather than guessed.

## Known limitations / acceptance
- Older KLOW data created before blend designation still needs an opt-in historical reconciliation flow. No automatic identity rewrite.
- Generic single- and multi-vial/Prepare flows require latest-head browser testing, including partial draws, undo, dose history and current-vial integrity before deployment.
- Physical iPhone Safari, keyboard, VoiceOver and full app-wide contrast acceptance: NOT TESTED for this release.

## Additional legacy compatibility and UI redesign (2026-10-25)
- **Legacy premixed kit setup:** Stash > kit actions > Mark as premixed blend. Enter real component names and mg per vial; the sum must equal existing vial strength, and an additional confirmation is required. Uses original vial `remainingMg` for legacy kits; no automatic conversion, no dose-history rewrite, and no re-deduction of previous administrations. A distinct legacy inventory mode protects future transactional draws.
- **Overview:** a prominent available quantity, progress indicator, and full-width secondary rows for vial counts, concentration and price. Notes and edit/intel actions are separated from the primary metric.
- **Vials:** sealed/open/finished summary first; opened vial cards show balance, date and contextual management.
- **Kit History:** first five records, with explicit Show All/Show Fewer. Existing older records remain accessible.
- **Today compound history:** first five doses initially, Show All/Fewer, plus an explicit Close history state. Existing edit/delete handlers remain available on expanded rows.
- **QA:** JS syntax parse passed for seven relevant modules. Latest-head browser functional/visual tests, opt-in legacy classification on real iPhone, privacy-preserving full DEMO, complete LIVE ZIP and Cloudflare deployment are unverified or incomplete. Do NOT mark released.
- **Personal-data protection:** private user backup was analyzed locally only; it is not copied into the GitHub branch or demonstration fixtures.
